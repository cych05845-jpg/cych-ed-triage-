【公告】編輯 board.json，每則一行：
  d = 日期（YYYY-MM-DD）　tag = 標籤（課程、作業、報告…）　t = 內容
  go = 點了跳到學習站哪一頁（可省略）：home、handout、practice、lookup、ref、pgy、games
  u = 點了開外部網址（可省略）
  b = 展開後顯示的詳細內容（可省略；換行請打 \n）。有 b 的公告會變成可點開的折疊卡片。
  今天以後的公告會排在最前面、底色標示。

【作品】編輯 works.json，每件一行：
  t = 作品名稱　a = 作者／單位　k = 類型（APP、講義、海報、品管…）　d = 一句話簡介　u = 連結（沒有就留空 ""）

在 GitHub 網頁點檔案 → 右上角鉛筆圖示 → 修改 → Commit changes。
注意：每行之間用逗號隔開，最後一行後面不要逗號；文字要放在英文雙引號 " " 裡。


【改用 Google 試算表發公告（建議，管理者不必碰 GitHub）】
1. 建一個試算表，第一列標題：日期｜標籤｜標題｜內容｜連結｜顯示
   日期寫 2026/10/20 或 2026-10-20；內容可以換行；連結可填網址或站內頁面（treat、obs、peds、resus、handout…）；顯示填「否」就暫時不出現。
2. 只把要管公告的人加為「編輯者」（用他們的 Google 帳號，這就是權限控管）。
3. 檔案 → 共用 → 發布到網路 → 選「公告」分頁、格式選 CSV → 發布，複製網址。
4. 把網址貼到 index.html 裡的 BOARD_CSV = "" 引號中（只要做一次）。
之後管理者改試算表，學習站約 5 分鐘內更新；試算表讀不到時會自動改用 board.json。
注意：發布到網路後任何人都看得到，公告內容不要放病人資料或內部專線。
